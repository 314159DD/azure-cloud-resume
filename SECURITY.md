# Security policy

Please report vulnerabilities privately via GitHub's "Report a vulnerability" (Security tab) or by e-mail to
arbeit.obst.steven@proton.me. Do not open a public issue. I aim to respond within a few days.

The security model of this project is described in the [README](README.md#security-model) and in
[ADR 2](docs/adr/0002-managed-identity-everywhere.md) and [ADR 3](docs/adr/0003-oidc-and-constrained-rbac-for-ci.md).
